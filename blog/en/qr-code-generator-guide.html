How to Use a Free Online QR Code Generator

2026-10-15 · 3 min read

Making a QR code used to require a designer, a subscription or an account. Today a good online generator turns an idea into a scannable square in under a minute — the trick is knowing which settings actually matter and which ones only look nice. This walkthrough covers the whole flow, from choosing a type to testing the finished file.

Step 1: Choose the Right Content Type

Start by deciding what the code should do. Most tools offer a list of types, and picking the correct one is the single biggest factor in usability:

  • URL — opens a web page, the most common choice;
  • Plain text — shows a short message with no internet needed;
  • Wi-Fi — joins a network without anyone typing a password;
  • vCard — saves your contact details into the phone's address book;
  • Email, phone or SMS — pre-fills a message or dials a number;
  • Payment — opens a payment link or wallet screen.

Step 2: Enter the Content

Type or paste the destination. Keep the payload as short as you sensibly can: the more characters a code carries, the denser the grid and the harder it is to scan from a distance. If a link is very long, consider a redirect or short link first, then encode the shorter version.

Step 3: Adjust Color and Size

Contrast is king. Dark modules on a light background scan best, so keep the foreground clearly darker than the background. Inverted codes (light on dark) work on some readers but fail on many, so avoid them for public use. Choose a size that suits the viewing distance: a code read from 1 metre should be at least a few centimetres across, and it should always sit inside a quiet, empty margin.

Step 4: Download PNG or SVG

Both formats have a job. PNG is a raster image — perfect for screens, chat apps and simple printing. SVG is vector art that stays razor-sharp at any size, which is what you want for signage, packaging and anything a professional printer will handle. Export once in each and keep the SVG as your master copy.

Step 5: Test Before You Print

Never send a code to print untested. Scan the downloaded file on screen, then print a single proof copy and scan that too, from the real distance people will use.
